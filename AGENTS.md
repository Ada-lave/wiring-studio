# Wiring Studio

- UI и MCP изменяют проект только через общий обработчик команд и Store. Не добавляйте второе хранилище во фронтенд или stdio-мост.
- Сети и номера выводов независимы от геометрии. Не меняйте подключения при переносе и повороте.
- Любая запись существующего проекта требует expectedRevision; пакеты атомарны. При конфликте перечитайте модель, не повторяйте устаревший пакет автоматически.
- Сохраняйте NC, источник импорта и статус assumed/verified. Подтверждённая физическая позиция требует документации; не угадывайте распиновку по иллюстрации.
- Не читайте/редактируйте нативные KiCad-файлы. При необходимости используйте KiCad MCP и экспортированный XML.
- Не называйте проверку модели ERC или симуляцией. Пример с БП 4 А требует программного ограничения LED до указанного бюджета.
- После изменений: npm run check, npm test, npm run build; для UI/рендерера npm run test:browser при запущенном сервере.
